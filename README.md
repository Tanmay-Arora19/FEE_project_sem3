# PulseWave - Music Streaming Platform

A modern, responsive frontend music streaming platform engineered with HTML5, CSS3, and JavaScript.

## Features
- **Modern UI/UX**: Premium dark theme with vibrant, standout branding and fluid micro-interactions.
- **Dynamic Content**: Browse featured playlists, popular artists, trending albums, and categorized channels.
- **Search & Filter**: Real-time category filtering and dynamic music exploration.
- **Authentication Flow**: Login and Sign-up state management with personalized avatar navbar integration.
- **Fully Responsive**: Optimized for desktops, tablets, and mobile screens.
